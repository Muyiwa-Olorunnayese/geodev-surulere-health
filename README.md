# GeoDev Lab Africa — Healthcare Accessibility in Surulere LGA

A geospatial analysis evaluating spatial access thresholds to public and private health facilities across Surulere LGA, Lagos State, Nigeria.

### Project Question
> **Which residential neighborhoods in Surulere Local Government Area sit more than 2 km from a primary or secondary healthcare facility?**

### Quick Overview
- **Study Area:** Surulere Local Government Area, Lagos State, Nigeria
- **Projected CRS:** EPSG:32631 (WGS 84 / UTM Zone 31N)
- **Primary Data:** GRID3 Nigeria & OpenStreetMap (QuickOSM)
- **Cohort:** GeoDev Lab Africa, Cohort One (2026)
